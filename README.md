# 🚀 Genora.AI — AI-Powered Website Builder

**Genora.AI** is a full-stack SaaS platform that empowers users to turn simple text prompts into fully functional, beautifully animated websites — deployed to the web in **one click** 🤯.

Built with a production-ready SaaS architecture, Genora.AI features an end-to-end credit system, secure payments via Stripe, protected authentication routes, and seamless cloud deployment.

---

## 🔥 Features

* 🤖 **AI Website Generation:** Describe your vision in plain English, and the AI generates complete web layouts instantly.
* 🚀 **One-Click Deployment:** Live hosting deployment triggered directly from the user dashboard.
* 💰 **Credit-Based System:** Users hold balance credits that deduct upon generating or modifying site projects.
* 💳 **RazorPay Payment Gateway:** Integrated RazorPay Checkout for buying credit top-ups.
* 🎞 **Fluid Motion Animations:** Polished UI using Framer Motion for smooth transitions and interactive micro-animations.
* 🔐 **Authentication & Security:** Secure auth flows, session management, and protected API routes.
* ☁️ **Production Ready:** Scalable frontend and backend architecture configured for live cloud hosting.

---

## 🛠 Tech Stack

### **Frontend**
* ⚛️ **React.js** — Component-driven UI framework
* 🎨 **Tailwind CSS** — Utility-first styling for fast, responsive design
* 🎞 **Framer Motion** — Production-ready animation library

### **Backend**
* 🟢 **Node.js** — Asynchronous server runtime
* 🚂 **Express.js** — RESTful API & routing service
* 🍃 **MongoDB** — NoSQL database for users, credits, and project metadata

### **Services & Deployment**
* 💳 **RazorPay** — Credit purchasing via Checkout API 
* ☁️ **Render** — Cloud platform hosting for both frontend and backend services
